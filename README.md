# 🧠 Machine Learning Algorithms from Scratch to Advanced

Welcome to my **Machine Learning Algorithm Collection**! 🚀  
This repository includes **over 25 ML techniques**, ranging from linear models to powerful ensemble learners, with **clear implementation and intuitive explanations**.

---

## 📘 What This Repository Offers

- ✅ Easy-to-follow Jupyter Notebooks
- 🧠 Basic intuition behind each algorithm
- 📈 Practical examples with visuals
- 🧪 Useful for learners, interviewees, and developers

## 📂 Directory Overview with Intuition

| # | Topic | Basic Intuition |
|--|-------|------------------|
| 0 | **Simple Linear Regression** | Models a straight-line relationship between input and output variables. |
| 1 | **Regression Metrics** | Measures model accuracy (e.g., MAE, MSE, RMSE, R²). |
| 2 | **Multiple Linear Regression** | Extends linear regression to multiple input features. |
| 3 | **Gradient Descent** | Optimizes the model by minimizing the loss function step by step. |
| 4 | **Batch, Stochastic & Mini-batch GD** | Variants of gradient descent for performance vs. accuracy trade-offs. |
| 5 | **Polynomial Regression** | Captures non-linear trends using polynomial terms. |
| 6 | **Ridge Regression** | Penalizes large weights to prevent overfitting (L2 regularization). |
| 7 | **Lasso Regression** | Can shrink some weights to zero, good for feature selection (L1). |
| 8 | **Elastic Net Regression** | Combines L1 and L2 regularization for better balance. |
| 9 | **Logistic Regression** | Estimates probabilities for binary classification using the sigmoid function. |
| 10 | **Classification Metrics** | Evaluates classifiers using accuracy, precision, recall, F1, etc. |
| 11 | **Logistic Regression (Multivariable)** | Logistic regression extended to multiple features. |
| 12 | **Decision Tree** | Splits data recursively based on feature values for classification/regression. |
| 13 | **Voting Ensemble** | Combines predictions from multiple models (hard or soft voting). |
| 14 | **Bagging (Bootstrap Aggregation)** | Trains models on random subsets and averages the results. |
| 15 | **Random Forest** | An ensemble of decision trees, reduces variance and improves performance. |
| 16 | **AdaBoost** | Focuses on previously misclassified examples and boosts weak learners. |
| 17 | **K-Means Clustering** | Groups data into `k` clusters by minimizing distance to centroids. |
| 18 | **Gradient Boosting** | Builds trees sequentially, each fixing errors from the previous. |
| 19 | **Stacking & Blending** | Combines different models using a meta-model for better performance. |
| 20 | **Agglomerative Hierarchical Clustering** | Clusters are formed by merging the closest pairs of points. |
| 21 | **K-Nearest Neighbors (KNN)** | Predicts by majority vote (classification) or average (regression) of closest points. |
| 22 | **Linear Regression Assumptions** | Assumptions like linearity, no multicollinearity, homoscedasticity ensure valid regression. |
| 26 | **Imbalanced Data Handling** | Techniques like SMOTE or class weights used to deal with skewed datasets. |
| 27 | **Hyperparameter Tuning (Optuna)** | Automatically searches for best model settings using trial-based optimization. |
| 28 | **ROC-AUC Curve** | Evaluates classifier performance using true positive and false positive rates. |
